TRACKING RAMP 7.0.0 — TEXT DISTRIBUTION STUDIO

RUN

In InDesign 2026, open Window > Utilities > Scripts > User > Tracking Ramp.jsx.
Select one ordinary text frame, highlight text, or put the text cursor inside
a frame, then double-click the script. V7 replaces the installed v6 entry.
This repository contains the current v7 script.

LIVE PREVIEW / CANCEL / APPLY

Live document preview is on by default. The actual selected text changes as
you adjust controls. Each update starts from the document state before the
current preview, so changes do not accumulate while experimenting.

Numeric fields wait until you pause typing for 350 ms before updating, so
entering 200 does not normally calculate after 2 and 20. Apply uses the latest
field values immediately. Cancel discards pending work and restores the session.
A pause longer than 350 ms can still preview a partially entered number.

Cancel, Escape, or closing the dialog restores the original formatting and
metadata, and removes any new preview metrics frames, layers and swatches.
This uses document-scoped Undo, preserving style overrides and inherited
formatting rather than merely rewriting numeric values.

Apply keeps the current result as one Edit > Undo Tracking Ramp 7 action.
Turn Live document preview off to work with the graph alone; turning it off
restores the document immediately. Apply still applies the configured effect.

The dialog initially appears toward the right of the main screen so the
page can remain visible. You can move the dialog by its title bar.

KEEPING EFFECTS / ADDING ANOTHER PROPERTY

Adjust a property as usual. Click + Add property and choose the next property.
The current effect is kept, and a read-only Kept strip appears. Continue with
the next effect, for example Skew followed by Tracking. The next curve samples
the composition produced by the kept effects. Their actual numeric formatting
stays frozen while the new property changes; they are not resampled against
the later property's composition.

Apply becomes Apply all. It commits the whole stack as one Undo Tracking Ramp 7
transaction. Cancel, Escape, or closing restores the document from before the
dialog opened, including kept effects, inserted breaks, contours and swatches.
Keeping an effect does not create a separate permanent document commit.

Undo addition discards the current draft and returns the last kept effect to
editing with its saved settings. Kept effects are read-only until returned this
way; reordering and arbitrary stage editing are not part of this version.
Each property is available once per stack, so the chooser omits properties
already kept. The existing Property selector still chooses the active draft.

Live document preview off restores the active draft while leaving kept effects
visible. Metrics are refreshed for the final visible state. A contour kept with
an earlier effect stays fixed; its width controls are disabled for later stages.

CHARACTER-STYLE BLEND

Choose Character-style blend in Property. Select Style A and Style B from this
document; grouped styles show their full group path. Min/Max are percentages:
0 is A, 100 is B, and intermediate positions interpolate all included values
at once. Use the existing curve, steps, Values per, Change and Restart controls.

Shared supported attributes are included automatically. Blend attributes opens
checkboxes to select a subset and lists missing/unsupported settings. Values
shared by both styles can also be constant: an explicit 24 pt in both styles
sets 24 pt throughout the blend. Based-on style values are resolved. Undefined
values are not taken from document defaults or guessed from the other endpoint.
Changing either endpoint selector resets the attribute selection to automatic.

Supported attribute types (22):
- Font size, tracking, absolute numeric leading, baseline shift.
- Horizontal/vertical scale, character rotation and skew.
- Fill tint, stroke weight and stroke tint.
- Underline weight, offset and tint; strikethrough weight, offset and tint.
- Fill, stroke, underline and strikethrough process colors in a shared RGB,
  CMYK or Lab color space.
- Complete variable-font design-axis vectors on the same physical font file
  with matching axis definitions; compatible named instances can differ.

Numeric limits follow the supported property ranges. Automatic leading,
automatic underline dimensions, inherited tint sentinels and one-sided/missing
endpoints are skipped. Spot colors, gradients, mixed inks and automatic Text
Color endpoints are not interpolated. Color blending uses up to 65 cached
levels, including exact endpoints and midpoint. Character rotation takes the
short angular route; other supported numbers interpolate linearly.

Font families, static font/style switches, capitalization, underline/strike
on/off, ligatures and other discrete switches remain as they are in the text.
Underline/strikethrough dimensions therefore need existing underlining/strike
formatting to be visible. Variable axes can change a variable font's displayed
instance name, but do not switch its font file. Target text must use that same
variable-font file when axes are included; otherwise the preview rolls back.
Exclude Variable-font axes to use the other shared numeric attributes instead.

The original character styles are never edited or assigned to the text by the
blend. Intermediate output is local formatting; existing character-style
assignment remains. A fresh UI reapply reads current endpoint definitions.
Keeping a blend freezes its resolved values like other kept effects. Cancel
restores the whole session and Apply/Apply all keeps one named v7 Undo action.

Replacement restores every previously controlled attribute before calculating
again, including attributes now excluded and targets outside a smaller scope.
Automatic leading and native Text Color tokens are preserved. Letters mode
preserves the outgoing tracking word gap while size/color/etc. still apply to
every eligible letter. Metrics continue to show actual integer tracking values.

Composition-sensitive blends apply all included attributes in each pass. The
existing Auto-stabilize/Fixed sampling rules still apply; blend mode does not
insert its own tracking-style break fallback. Allow added line breaks stays
off by default. Kept contours/paragraph structure from other effects remain.

Examples 18-20 in the visual guide demonstrate a long four-attribute ramp,
per-word character bells with exclusions, and variable weight plus size.
Endpoint styles are in Character Styles > Guide blends.

ALLOW ADDED LINE BREAKS

A separate toggle, off by default, controls whether the current effect may add
managed breaks. Auto-stabilize stays on by default and does not imply permission
to change text. With breaks off, cycling character-property distributions use
Fixed sampling. With breaks on, tracking can first try managed soft breaks.
Kept stages retain their saved policies and existing owned breaks.

LINE LENGTH - CENTERED

Min/Max specify 1-100% of the original usable frame width, with at least 1 pt
available. Default: 40-100%. Scope is Current frame, Values per Line, Change
Both and Restart Never. Former control choices return on selecting another
property. Both modes support the existing curve, inversion and step controls.

Allow added line breaks OFF (default):
- Preserve exact text, paragraph count and paragraph formatting.
- Shape the frame symmetrically to vary available width from top to bottom.
- The curve follows the full frame height; short text may use only part of it.
- Existing paragraph indents remain and reduce the space inside that contour.
- Auto steps uses a smooth contour; fixed Steps uses up to 200 contour bands.

Allow added line breaks ON:
- Fit each row at its assigned width; wider rows can take more words.
- Replace an existing space, tab or manual soft break with a managed paragraph
  return. Character count and indices stay unchanged. Do not split words.
- Use equal left/right indents and zero first/last-line indents on each row.
- Keep original paragraph returns and spacing at their outer edges. New internal
  rows add no paragraph spacing. Hyphenation is disabled and keep options are
  normalized; paragraph-aware styles can repeat on generated paragraphs.
- Justified paragraphs retain full justification on nonfinal generated rows.
- Refit changed row counts for up to eight passes. Auto-stabilize can retain the
  last safe widths with a visible Fixed sampling status; final rows can use
  only part of the sampled curve. Disable Auto-stabilize for strict rejection.

Both modes require one ordinary unthreaded rectangular frame, one column,
equal insets, auto-sizing off and no frame rotation/shear/scale. Automatic
lists/drop caps and combining a separate Line width contour are excluded.
Available width is not exact ink length. Very narrow widths can be rejected.

Reapply restores the owned frame shape or paragraph breaks before switching
modes. Cancel restores the starting document; Apply creates one named Undo.
+ Add property can keep either result before applying another property. A later
font/tracking change may rewrap paragraphs; kept indents/contours remain fixed.
After manual text edits or reshaping, safe ownership checks may reject replacing
an effect. A line-length contour remains separate from the Line width editor.

Visual-guide example 16 has added breaks ON; example 17 has them OFF.

TARGETS

Scope:
- Highlighted text: includes only the highlighted bounds, clipping partial words.
- Current frame: every unit mode follows the frame's resulting composition.
  Newly fitting text joins the distribution; text moving out returns to its
  baseline. Values are recalculated until the final visible range agrees.
- Entire story: includes linked frames and overset for word/character modes.

Values per:
- Character: one value per eligible InDesign character.
- Word: one value per word, or one per interword gap in Spaces mode.
- Sentence: one value across each punctuation-delimited sentence.
- Paragraph: one value across each paragraph.
- Line: one value per resulting composed line, recalculated until stable.
- Frame: one value across each visible linked frame's text, recalculated until
  frame boundaries agree with the resulting composition. Choose Entire story
  to distribute values across multiple linked frames.

Change:
- Letters: changes letters/punctuation and preserves spaces.
- Spaces: changes only interword spaces and preserves letters.
- Both: explicitly includes letters and internal interword spaces. In Word
  mode, each gap follows its preceding word's value.

Ordinary and typographic spaces are supported, including nonbreaking and
em/en spaces. Tabs, control markers, paragraph breaks, and leading/trailing
spaces are excluded. In line mode, spaces at the composed line edge are
excluded. Blank lines and units with no eligible targets do not consume steps.

STRUCTURE / RESTARTING THE CURVE

Scope decides which text is included. Values per decides the unit that gets
one value. Restart curve per decides where the complete curve starts again:
Never (entire scope), Word, Sentence, Paragraph, Line or Frame.

Examples:
- Font size, Values per Character, Restart per Word, Gaussian: a small-large-
  small pattern inside every word.
- Tracking, Values per Word, Restart per Sentence: a complete ramp or bell
  across the words of each sentence.
- Tracking, Values per Character or Word, Restart per Line: every resulting
  composed line receives its own complete distribution.
- Values per Line, Restart per Frame: a complete top-to-bottom text-property
  distribution in every linked frame.
- Values per Frame, Restart Never, Scope Entire story: frame 1 gets the first
  value, frame 2 the next, and so on.
- Restart Never: the v4 behavior, one continuous curve across the chosen scope.

Min/Max, curve and steps are shared by all groups. Auto steps is calculated
from the eligible unit count in EACH group. A fixed step count is separately
capped to each group's length. Empty groups do not consume a sample or a
preview-group number. One eligible unit receives the curve's starting value;
a bell needs at least three sampled stages for an interior peak. The UI
reports undersampled bell groups rather than silently promising a peak.

Preview group below the graph chooses which group's actual blue samples and
numeric values are displayed. The thin gray guide and orange handles describe
the shared curve. Changing Preview group only inspects it: it does not modify
that group's settings or touch the document/Undo transaction. Dragging points
or changing curve controls updates the same curve across every group.

Units that cross a restart boundary are split into disjoint fragments. A word
hyphenated across two lines can therefore receive each line's curve value on
its respective fragment. Choosing a larger unit inside a smaller group often
leaves only one fragment per group, producing a constant starting value.
Interword gaps follow the preceding word in Word/Both distributions and Word
restart groups. Line/frame restart groups exclude their outer whitespace.
Tabs, breaks and control objects are never text-property targets.

Partial selections clip groups to the selected bounds; the curve is sampled
across each included fragment. Nothing outside that scope is modified, apart
from replacing the previous saved effect when that option is enabled.

Sentence grouping uses punctuation, decimal/initial/common-abbreviation
handling, closing quotes and paragraph boundaries. It recognizes ASCII
period/question/exclamation marks, ellipses, Chinese/Japanese full stop and
fullwidth question/exclamation, and Arabic question marks. Smart quotes and
other visible InDesign special-character codes are normalized before parsing
and targeting. This is a deterministic heuristic, not a linguistic parser:
ambiguous abbreviations, URLs, unusual punctuation and other languages may
need review. Paragraph or Line grouping provides a more explicit boundary.

Paragraph breaks create paragraph groups; forced line breaks alone do not.
Line and Frame units OR restart groups follow actual frame-owned composition.
They exclude overset text, including when the scope is Entire story. Semantic
units with Restart Never/Word/Sentence/Paragraph can include overset in Entire
story scope. Frame scope follows its live boundaries for physical grouping.
The existing 24-pass/cycle protection also applies to these new combinations.

Values per Frame controls TEXT formatting inside linked frames. The separate
Line width feature still reshapes only the selected frame, mapped over its
fixed physical height. Linking its curve shares the shape of the curve; it
is not resampled over the typography's restart groups.

TRACKING AND THE WORD-GAP FIX

V2 preserved the numeric tracking on space characters but still changed
tracking on a word's last glyph. InDesign uses that glyph's outgoing tracking
in the word gap. The gap could therefore grow even with space tracking 0.

V3 Letters tracking excludes the last glyph before a space, preserving that
outgoing boundary as well as the space. Single-letter words can consequently
have no internal tracking target. Spaces mode changes the space character;
Both mode changes both boundaries explicitly. Other properties such as font
size still target the complete word: this boundary exclusion is specific to
tracking. Justification and font shaping can further affect visible spacing.

PROPERTIES

Tracking: whole numbers -1000 to 10000, in 1/1000 em.
Font size: 0.1 to 1296 pt.
Baseline shift: -1000 to 1000 pt.
Variable-font axis: axes and ranges are discovered from the first text font
in the selected scope. Choose an axis, then enter values in that axis's native
range. The script does not change the font automatically. Mixed-font targets
must all support the chosen axis name and requested values.
Horizontal and vertical scale: 1% to 1000%.
Character rotation: -360 to 360 degrees.
Skew: -85 to 85 degrees.
Text stroke width: 0 to 100 pt.
Text stroke tint: 0% to 100%.
Character color and Text stroke color: blend between document colors Color A and B. The colors
must share a color space: RGB, CMYK, or Lab. Up to 64 interpolated process
swatches are used. Min and Max control the blend position as a percentage.

Character tint: 0% to 100%, retaining the existing character fill color.
Character color retains existing fill tint.

Underline weight: 0 to 100 pt (default range 0.25 to 3 pt).
Underline offset: -1000 to 1000 pt (default range 0 to 8 pt).
Both enable underlining on eligible targets. Existing underline color, stroke
style and the other underline parameter are retained. Offset is relative to
the baseline: positive moves below, negative moves above. Characters, words,
spaces and restart groups work as with other character properties. Cancel
restores the exact starting state, including automatic weight/offset values.
Reapply restores previous targets before assigning new values. When weight
and offset effects coexist, replacing either retains the other's activation.

Paragraph left/right indent: 0 to 1000 pt (default range 0 to 36 pt).
Paragraph first-line indent: -1000 to 1000 pt (default 0 to 36 pt).
Negative first-line values create a hanging indent. Indent properties use
Values per Paragraph, Change Both and Restart Never; these controls are locked
while an indent property is selected. Selecting another property restores the
previous structure choices. Min/Max, steps and all curves remain available.

Indent scope means whole paragraphs intersecting the selected text or visible
frame range. A partial paragraph is included in full, even if it continues
in another frame or overset. Every paragraph, including blank paragraphs,
receives one value; the curve runs across those paragraphs. Reapplying a
narrower scope restores the previously affected paragraphs. Left, right and
first-line effects retain independent baselines. Large values can narrow the
measure too far, cause overset, or be rejected by InDesign; failed previews
restore the starting state.

Baseline shift moves glyphs without increasing leading. Large shifts, scale
values, skew or rotation can overlap neighboring text or extend past the
frame. Rotation is periodic: 360 degrees looks like 0. Native outline tests
confirmed that these controls change the actual rendered glyphs, including
60 pt baseline shift, 80 degree skew, 180 degree rotation and 300% scale.

Nontracking properties retain fractional values to three decimal places.
For stroke width/tint, existing stroke colors are retained unless the text
has no stroke color, in which case Color A is used. For color/tint, text
with zero stroke width receives the Width pt value so the result is visible.

Use + Add property to keep one effect while adjusting another in the same
dialog. Separately committing a different property also generally retains
the earlier property. Stroke width/color/tint also set related stroke
attributes when required for visibility; review these together when layering
several stroke effects.

LINE WIDTH / FRAME CONTOUR (V4)

Click Line width… at the top. Enable shaping, choose Min/Max, %, pt or mm,
and Keep left, Centered or Keep right. % refers to the original usable frame
width, excluding its equal insets. Widths must be at least 1 pt and fit within
that original envelope. The frame height remains fixed.

This changes the left/right frame path. It controls available line space;
ragged text, a paragraph's final line, paragraph indents, glyph dimensions,
text wrap and InDesign's inset/composition rules can produce shorter ink lines.
The frame's fill and stroke follow the new outline. Smooth contours use 97
bounded samples per side; stepped contours use 2–200 horizontal bands.

The curve maps to physical position from the original top to bottom, not
to the changing number of text lines. Text curve linking is on by default.
Unlinking copies the current text curve. Choose Edit > Width curve below
the graph to edit that independent curve with the same presets and draggable
points. Switching back to Text curve preserves both curves. Width band count
is set in Line width…; the main Auto steps/Steps controls belong to text.

Leave Apply text property on to combine width with typography. Turn it off
for width only. Shape is calculated before typography and resulting-line
recomposition. Width always applies to the selected frame, even if text scope
is Highlighted text or Entire story. Story threading is retained.

The first pass supports one ordinary column, equal insets, auto-sizing off,
and an unrotated/unsheared frame at 100% horizontal/vertical scale with one
path. Unsupported frames are rejected before a shape is kept.

The original path is stored separately from character-effect history. Reapply
starts from that same original path. Disable shaping to restore the original
path; Cancel restores the exact state present when the dialog opened. Manual
moving/reshaping after a committed contour is detected, avoiding a jump to a
stale page position. Undo that manual geometry edit or use a fresh base frame
before recalculating. This version does not automatically rebase moved frames.

CURVES / DRAGGABLE EDITOR

Presets: Linear, Ease in, Ease out, S-curve, Gaussian bell, Sine arch, Triangle.
Ease power controls easing strength. Gaussian Bell width controls its spread.
Invert swaps the high and low parts of a curve.

The orange handles are editable control points. Drag a handle to move it.
The first and last handles keep their horizontal positions but can move up
or down. Interior handles can move horizontally and vertically without
crossing their neighbors. This supports asymmetric peaks and multiple peaks.

Click empty graph space to add a point. Alt-click an interior point, or select
it and use Delete point, to remove it. There can be 2-24 control points.
Editing a preset switches to Custom. Reset curve returns to a linear ramp.
Smooth custom uses bounded interpolation without overshooting; turn it off
for straight segments between points. Custom curves honor the actual handle
heights; they are not automatically stretched to reach Min and Max.

Dragging updates the preview while movement notifications are available and
always uses the final release position. This accommodates InDesign/macOS
hosts that omit some drag-move events. The graph explicitly invalidates its cached native surface so handles and
curves repaint during adjustment. InDesign still needs time to recompose
the actual text. Custom-curve previews leave at least 250 ms after a
calculation before starting another during movement. Metrics are omitted
during curve dragging and rebuilt on release with the complete final result.
Sliders update the numeric field and graph during dragging; the document and
metrics update once on release, using the exact final value.

STEPS

Auto steps gives each eligible unit a sample within its restart group. Disable it and enter Steps
(1-10000) to spread that many stages over the selected scope. The effective
step count is capped by the available unit count. Several adjacent units
can share one value. Centered stage buckets keep bells symmetric with uneven
unit/stage counts. A step count describes samples along the curve, not the
number of distinct numeric values.

Bell presets reach exact Min at the ends and exact Max at their sampled
middle stage(s), including even counts. At least three stages are needed
for a bell peak. One or two stages only sample its endpoints. Invert turns
a bell into a valley. Equal Min/Max values give a constant effect.

The thin gray guide shows the continuous curve. Blue shows the actual
sampled distribution; above 500 units it is
visually sampled for performance. The numeric readout shows up to nine
values across the inspected group. Every eligible unit still receives its full value.

METRICS

Enable Metrics 5 pt to add a transparent overlay text frame above each source
frame containing visible targets. The overlay shows actual tracking values,
rounded to integers and aligned horizontally with their targets. This remains
tracking data even when another property is selected.

Each annotation row sits in the gap BELOW its source text row, centered
between the bottom of that row's glyphs and the top of the next row's glyphs.
The last row's labels sit below the last line. The positions account for
shifted baselines and the label font's actual ascent/descent. A unit spanning
multiple composed lines gets a label for each visible line fragment.

Labels remain 5 pt and are not omitted. Tight leading or dense character
labels can cause clashes: they remain centered, the UI reports tight gaps,
and source leading is never increased. The overlay is locked on the visible,
printable Tracking Ramp Metrics layer. Labels show in Normal and Preview
view and are included in ordinary print/PDF output. Rerun with Metrics enabled
and Apply to replace overlays created by older nonprinting builds.

Metrics require unrotated, unsheared source frames in this version. If the
source is transformed, turn Metrics off; the text effect itself can still run.
The overlay is a snapshot of the committed composition. Rerun the script to
refresh it after manually editing text or moving/resizing frames.

RESULTING COMPOSITION / FIXED LINE BREAKS

Frame scope now adapts in every unit mode, including Word and Character.
Each pass applies values, recomposes, reads the new visible text and line/frame
groups, restores the baseline, and recalculates. Text leaving the frame is
restored; text newly fitting is sampled. With live preview on, the status shows
the number of passes. With live preview off, this happens when you press Apply.

Line/Frame units and Line/Frame restart groups use the same loop even in
selection or entire-story scope. Whole-story scope includes visible composed
lines across linked frames. Overset has no visible line/frame group. For
tracking, a changed layout can settle if every target already has exactly the
value required by the resulting composition, including restored targets.

Some exact curves have no stable natural result: a word moves to the next
line, gets a different value, and moves back. The solver detects cycles or
stops after 24 passes rather than retaining an inconsistent curve.

Auto-stabilize composition is on by default. It first tries the exact live
solver. Allow added line breaks is a separate toggle, off by default. Only
when it is on, tracking can try a conservative layout on a cycle/pass limit
at Max tracking and inserts managed soft line breaks at safe word gaps. This
can fit fewer words than an unconstrained layout. Automatic hyphenation is
temporarily disabled to find gaps and then restored. Composer and justification
are unchanged. The status reports the number of fixed breaks.

With added breaks off, if tracking cannot be stabilized by permitted breaks,
or when another property cycles, the
fallback assigns the curve once and keeps those assignments as text reflows.
The status says Fixed sampling. Min/Max and assigned numeric values are not
rescaled. The final line/frame groups can differ from the sampled groups;
this fallback prioritizes a usable result over an exact curve in every final
line. In Current frame scope, targets leaving the frame are restored without
redistributing the remaining values. Newly fitting text can retain its baseline.
Clear tracking is limited to the retained sampled range in this fallback too.
Paragraph indents remain atomic and can affect full paragraph continuations.

Cancel removes new breaks and restores formatting and metadata. Reapplying
Tracking with Replace removes its previously managed breaks before recalculating,
so they do not accumulate. Other properties retain them. Manual Undo restores
the entire previous state. After manual text edits, ownership is no longer
trusted: disable Replace to adopt the current breaks as ordinary text and
establish a new baseline.

Disable Auto-stabilize to require strict natural convergence. Invalid native
property values, missing font axes, or an effect leaving no visible targets
can still be rejected safely. Fully justified composition can compensate for
tracking through other spacing settings: numeric tracking and visible gaps differ.

REAPPLYING / RESETTING OLDER EFFECTS

Replace previous effect is on by default. V7 retains compatible v3/v4/v5/v6 history
and saves the original affected
property values in the story's metadata. Reapplying restores the previous
baseline before calculating the new result, including old targets that are
no longer included by the new mode. Narrowing a range or switching from Both
to Letters therefore does not leave the previous tracking on old gaps.

There is one replaceable effect per property per story. This is story-wide,
as stated in the checkbox; applying to another linked frame can replace that
property's previous effect. Disable Replace for an independent additional
effect or to start from the current formatting.

The original values from v1/v2 were not saved and cannot be reconstructed.
For those cases, enable Clear tracking to 0 first. It clears tracking across
the chosen scope before applying the new distribution. In Current frame scope,
this clear follows the final visible range too: incoming gaps are cleared and
outgoing overset retains its previous baseline. Cancel still restores
what was there when the dialog opened. A committed clear establishes zero
as the saved baseline for later replacement runs, so old v2 gap tracking does
not return when the option is left off on a later run. Manual Undo still
restores the pre-clear formatting.

If the text content changes after a v3 commit, saved indices may be invalid.
The script detects this and asks you to disable Replace to establish a new
baseline. It does not apply old index-based history to changed text.

LIMITS / VERIFICATION

Ordinary frames and one contiguous selection are supported. Multiple-frame
selection, table-cell text, footnotes, endnotes, text on paths and grouped-frame
selection remain outside this version. Character mode uses InDesign's native
Characters collection, not a custom Unicode grapheme engine. Complex scripts,
combining characters, emoji and ligatures need additional typographic review.

Preview performance depends on story length and composition complexity.
The script changes local formatting; applying paragraph/character styles
later can replace those overrides. Locked source text/layers may reject writes;
failed preview transactions are restored.
